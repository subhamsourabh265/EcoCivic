# Cross-application tests

- `e2e/`: Playwright journeys spanning the shell, MFEs, and API.
- `integration/`: interactions across service boundaries.
- `contracts/`: API and event compatibility checks.
- `fixtures/`: synthetic test data and reusable fixtures.

Keep unit and component tests close to their owning application or package. A future end-to-end scenario covers report creation, another citizen's confirmation, moderator verification, and authority resolution.
